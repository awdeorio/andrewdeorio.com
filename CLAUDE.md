# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Commands

```bash
# Regenerate the publications section in docs/index.html from the .bib database
./build

# Validate HTML, check links, verify images, confirm publications are up-to-date
./test
```

Both scripts must be run from the project root.  `./test` requires `html5validator`, `linkchecker`, `bibble` (Python packages), and `imagemagick`.  `bibble` may be installed in `.venv/bin/bibble`; activate the virtualenv if it is not on `PATH`: `source .venv/bin/activate`

## Architecture

This is a single-page static site deployed via GitHub Pages from the `docs/` directory.

**Publications workflow.**  The publications list in `docs/index.html` is not hand-edited.  It is generated by `bibble`, a Python tool that combines:
- `publications_database.bib` -- BibTeX database of papers
- `publications_template.html` -- Jinja2 template for each entry

`./build` replaces the content between `<!-- BEGIN BIBBLE -->` and `<!-- END BIBBLE -->` markers in `docs/index.html` with fresh bibble output.  Always run `./build` after editing the `.bib` file; `./test` will fail if they are out of sync.

**CSS / JS.**  The page uses [Fomantic UI](https://fomantic-ui.com/) (a Semantic UI fork) and [Academic Icons](https://jpswalsh.github.io/academicons/) loaded from CDN -- no local build step for styles.

**Images.**  All images in `docs/assets/images/` must be under 100 kB and must contain no EXIF data.  Strip EXIF with ImageOptim before committing.

**Deploy.**  Pushing `main` deploys automatically via GitHub Pages.
